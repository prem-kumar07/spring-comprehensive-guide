Spring AI

Spring AI 1.x Spring AI 2.x

Spring AI is an application framework for AI engineering that provides a portable, unified API across AI model providers — covering chat, text-to-image, audio transcription, text-to-speech, and embedding models. It embraces Spring Boot idioms (auto-configuration, starters, dependency injection) so adding AI capabilities is as straightforward as adding a database integration.

8 Core Pillars ChatClient · EmbeddingModel · VectorStore · RAG · Tool Calling · Advisors · Structured Output · Document ETL

Version Timeline

Spring AI moved from milestone builds in 2023 to its first GA in May 2024. The 1.x line added MCP client/server support and RetrievalAugmentationAdvisor. Spring AI 2.0 went GA on June 12, 2026, lifting the tool-calling loop into the advisor chain via ToolCallingAdvisor and adding annotation-driven MCP server authoring.
