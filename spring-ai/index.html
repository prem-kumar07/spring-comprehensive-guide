Spring AI

Spring AI 1.x Spring AI 2.x

Spring AI is an application framework for AI engineering that provides a portable, unified API across AI model providers — covering chat, text-to-image, audio transcription, text-to-speech, and embedding models. Rather than shipping a model of its own, Spring AI acts as the integration layer between your Spring Boot application and the underlying provider, so you can swap from OpenAI to Anthropic to a local Ollama instance by changing a single property with no changes to application code. It embraces the Spring ecosystem idioms — auto-configuration, starter dependencies, and the familiar annotation-driven programming model — to make adding AI capabilities as straightforward as adding a database integration.

8 Core Pillars ChatClient · EmbeddingModel · VectorStore · RAG · Tool Calling · Advisors · Structured Output · Document ETL

Architecture

Spring AI inserts a vendor-neutral abstraction layer between your application and the chosen model provider, translating Spring idioms (auto-configuration, dependency injection, @Tool annotations) into each provider's native API format at runtime.

Provider Landscape

Spring AI 2.0 ships first-class support for 20+ providers organized into three tiers: commercial frontier APIs with the deepest feature coverage, additional cloud APIs for specialized workloads, and local runtimes for air-gapped or cost-sensitive deployments.
